Project name: Age Calculator

Project Overview:



The Age Calculator is a beginner-friendly web development project designed to demonstrate the use of:

    HTML for webpage structure.
    CSS for styling and responsive design.
    PHP for date calculations and backend processing.
    XAMPP for running the PHP application locally.

The application provides an attractive interface where users can select their date of birth and instantly view their age and birth day.

Age Calculation:
Calculates the user's exact age in:
Years

Birth Day:


Displays the day of the week on which the person was born.

For example:


Date of Birth: 13 August 2005


Born On: Saturday

Date Validation:


The application prevents users from entering a future date as their date of birth.

Technology used :

steps to run :

Step 1: Install XAMPP

Download and install XAMPP on your computer.

Make sure Apache is available.

Step 2: Open htdocs

Go to your XAMPP installation directory:

C:\xampp\htdocs

Step 3: Create Project Folder

Create a folder named:

age-calculator


Step 4: Add Project Files

Place the following files inside the folder:

age-calculator/
│
├── index.php
├── style.css

Step 5: Start Apache

Open the XAMPP Control Panel and start:

Apache
Step 6: Open the Application

Open a web browser and enter:

http://localhost/age-calculator/

The Age Calculator will now open in your browser.
